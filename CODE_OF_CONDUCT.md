# Code of Conduct

## Our commitment

INFÆMOUS FREIGHT is a logistics technology project. We expect contributors, maintainers, operators, and community members to work professionally, respectfully, and responsibly.

We are committed to a project environment that is welcoming, focused, and free from harassment.

## Expected behavior

Examples of expected behavior include:

- using respectful and professional language
- focusing feedback on the work, not the person
- giving clear, actionable technical feedback
- respecting different experience levels and backgrounds
- protecting sensitive operational, customer, driver, shipment, and billing data
- avoiding public disclosure of credentials, vulnerabilities, or private production details
- following repository security and contribution guidelines

## Unacceptable behavior

Examples of unacceptable behavior include:

- harassment, threats, insults, or discriminatory language
- publishing private contact, customer, driver, carrier, billing, or shipment data
- sharing credentials or private production data
- intentionally disrupting issues, pull requests, discussions, or reviews
- submitting malicious code or instructions
- bypassing documented review, launch, or security processes

## Production-sensitive conduct

Because this project handles freight, billing, and operational workflows, contributors must be careful with:

- environment variables
- production logs
- credentials
- API keys
- billing information
- shipment records
- driver and carrier data
- customer information

Do not paste sensitive information into public issues, pull requests, comments, screenshots, or logs.

## Reporting concerns

For general conduct concerns, open a private maintainer discussion or contact the project maintainers through the appropriate repository channel.

For security vulnerabilities, do not open a public issue. Follow [`SECURITY.md`](SECURITY.md).

## Enforcement

Maintainers may remove comments, close issues, restrict participation, or block users who violate this code of conduct. Enforcement decisions should prioritize user safety, production safety, project integrity, and professional collaboration.

## Attribution

This code of conduct is adapted for INFÆMOUS FREIGHT's production-sensitive logistics context.
